#  ThunderFlow

ThunderFlow is an AI-powered UI-to-Code Generator that converts UI screenshots into clean frontend code.

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL

### AI
- OpenAI / Groq API

## Features

- User Authentication
- Upload UI Screenshot
- AI Code Generation
- Code Preview
- Download Generated Code
- Project History

 Currently under development.
